### Typography
- Display font: Satoshi (fontshare.com/fonts/satoshi)
- Body font: Plus Jakarta Sans (Google Fonts)
- Type scale: 12/14/16/18/24/32/48/64/96/128 rem
- Hero H1 class: `text-7xl` (72px), font-bold, leading-tight
- Letter-spacing: -0.02em hero / 0 body / 0.05em uppercase eyebrows

### Color
- Primary hex: #1B3A5C (warm navy — hero panels / nav / primary sections)
- Accent hex: #C8A04A (warm gold — CTA / eyebrow / stat highlights)
- Secondary hex: #0E7C9E (teal — links / icon fills / trust tags)
- Neutral light: #FBF7EF (warm white — section backgrounds)
- Body text: #2C3E50
- Brand shadow: rgba(200,160,74,0.15) `shadow-brand` / rgba(200,160,74,0.25) `shadow-brand-lg`

### Motion vocabulary (GSAP-implemented)
- Hero entrance: staggered fade-up — eyebrow → H1 → subheadlines → journey steps (scale+stagger)
- Scroll reveals: `.gsap-reveal` autoAlpha 0→1 + y 24→0 on ScrollTrigger `start: top 82%`
- Button hover: magnetic `gsap.quickTo` + shine sweep on `.btn-shine`
- Page transitions: gold overlay `astro:before-swap`/`astro:after-swap` (GSAP)
- FAQ accordion: plus-to-minus rotation + GSAP height, 0.3s

### Anti-patterns
- No `motion`, `motion/react`, `framer-motion` anywhere
- No cold electric teal as primary accent (gold leads)
- No CSS @keyframes — GSAP only
