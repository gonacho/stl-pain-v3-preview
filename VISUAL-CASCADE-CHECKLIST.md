# Visual Cascade Checklist — St. Louis Pain Center

This checklist is the source of truth for "is this site visually complete?" QA Auditor verifies 100% completion before Launch QA approves.

The five cascade elements per page (all GSAP — never motion/react):
1. Hero motion (GSAP fade-up + stagger, ScrollTrigger where appropriate)
2. Image-backed cards (real images, no solid-color placeholders)
3. Section alternation (light/dark rhythm)
4. Reveal animations (scroll-triggered via GSAP ScrollTrigger)
5. End-of-page CTA (image-backed + GSAP hover motion)
